# K-DPP 작업 인계

`docs/HANDOFF.md`는 Codex와 Claude가 함께 읽는 **현재 상태**다. 장기 규칙은 `AGENTS.md`, 확정된 파서 결정은 `docs/DECISIONS.md`에 둔다.

1. `AGENTS.md`, 기존 인계, 현재 요청을 읽고 실제 날짜·시각, `git status --short --branch`, `git log -1`을 확인한다. 원격은 확인하지 않았으면 미확인으로 적는다.
2. 현재 목표, 완료한 변경과 검증 근거, 미검증 사항, 다음 행동, 사용자 소유의 미커밋 변경을 갱신한다. 압축된 대화나 요약에 의존한 부분은 표시한다.
3. 완료된 과거 서사와 상시 규칙을 복제하지 않는다. 인계는 120줄 안에 유지하고, 확인하지 않은 결과를 성공으로 기록하지 않는다.
4. DB·서버·Vision·모델을 인계 문서 작성 때문에 실행하지 않는다. 자격증명, 개인 경로, 원문 OCR을 기록하지 않는다.
5. 인계 갱신에는 커밋·푸시 권한이 포함되지 않는다. 수정 후 기준 커밋·참조·문서 형식을 확인하고 결과를 간단히 보고한다.
