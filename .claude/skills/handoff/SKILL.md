# K-DPP Claude 작업 인계

`docs/HANDOFF.md`는 Codex와 Claude가 함께 읽는 **현재 상태**다. 프로젝트 상시 규칙은 `CLAUDE.md`가 가져오는 `AGENTS.md`, 오래 유지할 결정은 `docs/DECISIONS.md`에 둔다.

1. 실제 날짜·시각, `git status --short --branch`, `git log -1`을 확인하고 인계의 기준점과 대조한다. 원격 상태는 실제로 확인했을 때만 기록한다.
2. 완료한 변경·테스트, 미완료 작업, 다음 행동, 미커밋·미추적 파일과 사용자 소유 변경을 갱신한다. 요약 또는 다른 에이전트의 기록에 의존하면 출처를 표시한다.
3. 긴 과거 이력과 상시 규칙은 복제하지 않는다. 인계는 120줄 안에 현재 상태만 남긴다.
4. 문서를 쓰기 위해 백엔드·Vision·모델을 실행하거나 DB·캐시를 변경하지 않는다. 자격증명과 개인 경로를 기록하지 않는다.
5. 인계 갱신에는 커밋·푸시 권한이 포함되지 않는다. 기준점·참조·문서 형식을 확인하고 결과를 간단히 보고한다.
