# AI 최종 평가 정리 - 2026-10-15

현재 로컬 수정본의 **저장 OCR 평가를 최종 집계한 문서**다. 독립된 새 실사진 평가나 앱 전체의 출시 검증을 완료했다는 뜻은 아니다.

기준 브랜치는 `ai-integration`이며 부모 게시 커밋은 `da62998ef698c5b6599f65070c071185401ade14`다. 이후 재촬영 안내·좌표 경계·파일 제외와 공통 자동 보안을 보완했다. 저장 평가는 실행 코드 34개의 해시가 직전 OCR 재생 때와 같음을 확인하고 저장 응답을 다시 채점한 결과다. 후속 전체 회귀와 보안 검증은 6절에 구분한다. 새 Vision 호출·기존 캐시 갱신은 하지 않았다.

## 1. 현재 판단

소재·혼용률과 겉감 미완성 거절 규칙은 회귀 자료에서 개선을 확인했다. 다만 **실사진 소재 성공 44건 중 32건은 부위 미확정**이므로, 소재 일치율을 겉감 확인율로 설명하면 안 된다. AI가 관측한 겉감이 불완전할 때 안감으로 대신 성공하는 동작은 막았지만, OCR이 겉감 표기 자체를 놓친 경우까지 해결됐다고 보장할 수 없다.

현재 우선 확인할 제품 항목은 부위 미확정 표시·계산 적용 기준, 계산 미지원 소재의 오류 처리, 탄소계수 출처다. AI 내부 근거가 준비된 상태와 앱에서 사용자가 볼 수 있는 상태를 구분한다.

실사진 두 기록의 같은 사진 관계는 입력 명세의 해시·정답·부위·계열을 대조했다. A/B 결과를 독립 실사진 100장의 정확도로 합치지 않는다. 변형 200건 역시 개발에 쓴 계열의 조건별 회귀 자료이며 독립 일반화 평가가 아니다.

실사진의 DJ030·DJ046은 기존 입력 명세의 평가 제외 항목을 그대로 유지했다. 이번 결과를 높이기 위해 새로 제외한 사진은 없다. 변형 DJ023 영어 회전은 저장 응답이 부족하지만 분모 200에 유지했다.

채점 규칙은 다음과 같다.

- **소재·비율 일치:** 자동 성공이고 정답지와 소재 및 비율이 일치해야 한다. 주 지표는 허용오차 0%p다. 기존 AI QA 비교기의 소재 동등성 규칙을 그대로 사용한다.
- **소재·대표 부위 일치:** 위 조건과 `selected_part == answer_part`를 함께 요구한다. 정답의 `generic`도 같은 값이면 일치로 세므로, 이 지표가 명시적인 겉감 확인율은 아니다.
- **부위 미확정:** 자동 성공 중 `selected_part=generic`인 결과를 따로 센다. 실제 겉감이나 의류 전체 조성이 확인된 결과로 표시하지 않는다.
- **성공 소재 오답:** 자동 성공했으나 소재·비율 정답에 맞지 않은 결과다. 평가 전체 대비와 성공 결과 대비 분모를 함께 적는다. 부위 미확정 위험은 별도로 남긴다.
- **계열 전체 일치:** 한 계열의 평가 대상 이미지가 모두 일치해야 그 계열을 통과로 센다. 여러 사진 중 가장 잘 나온 결과를 골라 쓰지 않는다.
- AI 단위 QA의 ±3%p 보조 점수, 백엔드 통합 QA의 기본 ±5%p, 문자 단위 정확도는 서로 다른 지표다. 이번 자료에서는 0%p와 ±3%p 결과가 같았다. 문자 오류율은 측정하지 않았다.

## 7. 호출 수·시간·비용의 해석

| 이번 최종 집계가 참조한 저장 OCR 재생 | 실사진 A | 실사진 B | 변형 |
| --- | ---: | ---: | ---: |

93회나 314회는 저장된 입력 시도 이력이며 이번에 청구된 RPC 수가 아니다. 캐시 누락 시도도 포함할 수 있다. 일본어 회전의 입력 시도가 4→2회로 줄었고 다른 299개 기록은 시도 수를 유지했다.

현재 기본 정책은 원본·기본 전처리·필요한 소재 영역 후보를 합쳐 최대 4입력, OCR 시간 예산 25초다. 실제 RPC는 재시도로 입력 수와 달라질 수 있고, 25초는 앱 왕복 응답 보장 시간이 아니다. 현행 코드의 새 Vision 처리 시간 중앙값/P95·실기기 왕복 시간·실제 청구 비용은 이번에 측정하지 않았다. 과거 전처리 시간이나 오프라인 재생 시간을 현재 서비스 지연으로 사용하지 않는다.

| 중간 | 남은 인식 실패·독립 평가 | 문자/영역 근거를 보존해 개선. 새 사진이 어려우면 기존 미사용 원본의 사용·중복 이력을 확인하고 정답을 검수한 뒤 분리. 변형 추가만으로 독립성을 주장하지 않음 |
| 중간 | 앱·배포·원격 CI 확인 | 로컬 전체 회귀 4,581건·격리 DB 14건은 통과. 실기기·배포·정확한 게시 커밋의 CI는 별도 확인. 새 Vision·서버·배포는 요청 범위에서 진행 |
| 중간 | 보안 게시·공유·관리자 적용 | 공통 내용 검사·로컬 훅·보안 CI 코드/22개 검사는 완료. 게시 커밋 CI 확인·`kyh/ai` 코드 공유·새 PC 설치·관리자 푸시 보호/필수 검사는 별도 |

AI 소재 사전은 26종, 저장소의 백엔드 시드는 22종이다. `acetate`, `alpaca`, `hemp`, `triacetate`의 계산 지원은 현재 시드 기준으로 부족하다. 배포 DB의 카탈로그는 별도로 확인해야 한다. 올바르게 인식한 소재를 임의의 다른 소재로 바꾸어 계산을 통과시키지 않는다.

세탁기호 ResNet18은 잘라낸 단일 기호의 과거 실험이다. 전체 라벨 기호 검출·제품 기본 연결·AI 수명 예측·세탁 단계 탄소 효과를 구현 성과에 포함하지 않는다. 현행 OCR은 Google Vision을 사용하며 직접 학습한 OCR 모델의 성능으로 소개하지 않는다.
