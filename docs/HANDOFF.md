## 미완료·미검증

- `pytest==9.0.2` 변경은 `31d1beb`에 포함했다. GitHub 전체 검사 통과 여부는 아직 모른다.
- `tests/test_backend_ai_wiring.py`를 포함한 전체 AI 검증과 새 백엔드 테스트는 미실행이다. AI 가상환경에 `python-dotenv`가 없고 백엔드 import가 로컬 SQLite를 변경할 수 있다.
- 이 PC에서 Flutter 명령을 확인하지 못해 프론트엔드 분석·테스트와 앱 연동을 실행하지 않았다.
- 위 수치는 OCR+파서의 소재 혼용률 정확도이며 Vision 단독 문자 인식률은 아니다. 실사진 163장 중 74장은 정답이 없고, 중국어 1장·일본어 4장으로 언어별 표본이 작다. 실패 원인의 Vision/파서 기여도와 앱 연결·수동 입력 흐름은 미검증이다.
- `/api/scan`은 혼용률 합계가 부족하면 HTTP 200에 `ai_success=false`, `RATIO_INCOMPLETE`를 주지만, 프론트엔드 `ScanApiService`는 이 필드를 읽지 않아 정상 스캔 흐름으로 보낸다. 저장 전 합계 검사는 별도로 있다. 프론트엔드 성공 응답 fixture에는 현재 API가 반환하지 않는 탄소값·저장 ID가 들어 있다.
- 현재 점검 셸에는 `GOOGLE_APPLICATION_CREDENTIALS`가 없고 백엔드 `.env`와 저장소 내 `key.json`도 없다. 별도 기본 인증이나 다른 서버 프로세스 환경은 확인하지 않았다.
- 세탁기호 경로에는 전체 라벨 위치 검출이 없고 실제 데이터셋·체크포인트가 저장소에 없어 모델 성능을 확인하지 못했다. 사용자가 지난주 회의에서 세탁기호 기능 채택이 미정으로 끝났다고 알려 3번 문제는 보류했다.
