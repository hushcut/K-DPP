# 면·폴리에스터 계수 1차 검토

검토일: 2026-09-11. 기준: [탄소배출 추정 기준서](CARBON_CALCULATION_STANDARD.md) v0.1.

## 판정

후속 검토: [2차 호환성 판정](CARBON_FACTOR_COMPATIBILITY_V2.md). EF 3.1 공통 지표가 확인되어 방법 대조가 진전되었으며, 아래 '추가 확인 필요' 항목은 1차 검토 당시 상태다.

문헌 후보 수치 확인은 완료했다. 일반 의류용 기본 계수 선정과 혼용 계산 적용은 보류한다. 문헌값의 정확한 인용과 불특정 의류에 대한 적용 타당성은 별개의 판단이다. 이번 결과는 코드와 운영 DB에 적용하지 않았다.

## 원문과 값

- C: [Textile Exchange Cotton LCA Technical Report, 2026](https://textileexchange.org/app/uploads/2026/03/Cotton-LCA-Technical-Report.pdf)
- P: [Textile Exchange Polyester LCA Technical Report, 2026](https://textileexchange.org/app/uploads/2026/06/Polyester-LCA-Technical-Report.pdf)

페이지는 보고서 인쇄 페이지. 단위는 kg CO₂eq/kg fiber. 모든 행은 `evidence_type=literature`, `review_status=candidate`다.

C: 재배~조면, IPCC AR6 GWP100, 생물기원 CO₂ 제외·토지이용변화 포함. 평균의 생산 가중 기준은 2023년이며 세계 생산량 약 53%를 포괄한다. 국가별 원자료 연도는 추가 추출 필요. 한국 시장 평균은 아니다.

P: 원료~단섬유, 본문 방법은 IPCC 2021 GWP100. SF1은 섬유 생산 중 색소 투입이 포함된다. 평균은 세계 평균이 아니다. 사례별 원자료 연도, 생물기원 탄소 처리 일치 여부는 추가 확인 필요.

## 기준서와 대조한 적용 판단

| 검토 항목 | 확인 결과 | 후속 처리 |
| --- | --- | --- |
| 원문 수치 | 위 표에서 확인 | 원문 총값 유지; 반올림된 부분값을 다시 합산하지 않음 |
| 기능단위 | 면 섬유와 PET 단섬유 | PET 칩·POY·DTY를 같은 계수로 취급하지 않음 |
| 생산 형태 | 라벨의 polyester만으로 단섬유 여부 불명 | 일반 polyester 자동 매핑 근거 필요 |
| 착색 경계 | SF1은 색소 투입 포함 | '염색 제외'가 섬유 생산 중 착색까지 의미하는지 기준서에서 구분 필요 |
| 대표성 | 면 제한된 가중 평균, PET 사례 평균 | 사용 범위를 명시한 연구용 대체값 후보로 유지 |
| 영향평가 | 모두 100년 지평의 2021 IPCC 계열 | 생물기원 CO₂와 토지이용 처리까지 확인 후 혼합 가능 판정 |
| 사용 목적 | 보고서 p.4에 활용 안내 | 내부 추정 입력과 공개 제품 주장·비교를 구분; 앱 활용 적합성 미확정 |

P의 4.55는 보고서 자체의 평균이다. 이전 대화의 개별 사례 목록을 보완하는 값이며, 우리 팀이 새로 정한 기본값은 아니다. 3.96~4.93 또는 면의 1.29~4.17은 관찰된 사례 범위일 뿐 오차 범위로 사용하지 않는다.

## 추정값 관리

후보 평균을 연구용 입력으로 적용할 수는 있지만, 선정 전 사용자 계산 기본값으로 승격하지 않는다. 검토 중 값은 기존 개발용 값과 별도로 관리한다. 나머지 20개 seed 소재의 근거는 이번에 확인하지 않았으므로 검증 완료나 미지원 기능 구현 완료로 표시하지 않는다.

## 계수 확정 전 남은 작업

1. P의 생물기원 탄소 처리와 C의 제외 기준을 대조한다.
2. 원자료 연도·지역·생산 형태와 앱의 대상 의류 간 차이를 기록한다.
3. 일반 폴리에스터에 단섬유 대체값을 적용할 근거 또는 더 적합한 공개 자료를 확보한다.
4. 원문 활용 안내에 맞는 연구·시연 결과 표시 범위를 정한다.
5. 해결 후 선정 사유와 버전을 기록한다. 해결되지 않으면 다른 출처를 조사한다.

## 구현에 전달할 조건

후보 데이터는 기존 materials seed와 분리한다. 선정 상태, 단위, 적용 조건, 출처 위치를 저장할 구조를 먼저 설계한다. 계수 적용은 원문 검토가 완료된 후 수행한다. 기존 수치와 새 수치의 차이를 탄소 절감 효과로 표시하지 않는다.
