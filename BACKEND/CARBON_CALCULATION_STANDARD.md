# K-DPP 탄소배출 추정 기준서

- 문서 버전: 0.2
- 작성일: 2026-09-11
- 상태: 팀 검토용 초안
- 적용 대상: K-DPP 졸업작품의 라벨 기반 탄소배출 추정 기능
- 문서 성격: 향후 구현 및 계수 선정 기준. 현재 코드가 아래 요구사항을 충족한다는 의미는 아니다.

## 1. 목적

의류 라벨에서 확인한 소재·혼용률과 실측 또는 추정 무게를 이용해, 의류에 포함된 섬유 소재의 생산 단계 온실가스 배출량을 추정한다. 사용자가 결과의 근거와 한계를 확인할 수 있도록 입력값, 계수 출처, 적용 가정 및 계산 버전을 제공한다.

제품별 공급망 정보가 없는 상황에서 사용하는 참고용 모델이다. 실제 제품의 검증된 탄소발자국, 공식 DPP 인증 또는 전체 생애주기 평가 결과로 표현하지 않는다. OCR의 인식 정확도와 탄소배출 추정의 타당성은 별도로 평가한다.

## 2. 계산 대상과 경계

### 2.1 기준 대상

추정 대상은 의류에 포함된 섬유 질량에 대응하는 원료 획득부터 섬유 생산 완료 시점까지의 배출이다. 계수의 기능단위는 원칙적으로 `섬유 1kg`, 결과 단위는 `kg CO₂eq`로 한다.

천연섬유와 합성섬유는 생산 경로가 다르므로 계수별 종료 지점과 제품 상태를 기록한다. 면의 조면 완료 섬유, 합성 단섬유, 필라멘트사, PET 칩, 완성 원단은 자동으로 같은 단계로 취급하지 않는다. 여러 소재를 하나의 식에 사용할 수 있는지 계수 검토표에서 판정한다.

### 2.2 초기 제외 범위

- 방적·제직·편직 등 원단 생산과 섬유 생산 완료 이후의 염색·후가공
- 재단·봉제 등 의류 제조
- 원단·의류의 후속 운송, 판매 및 포장
- 사용·세탁·건조·수선·폐기·재활용
- 단추·지퍼·코팅 등 별도 부자재의 생산 배출
- 섬유 이후 공정에서 발생하는 재료 손실 및 추가 투입량

섬유 생산 계수에 이미 포함된 상류 운송·에너지 사용은 그 계수의 경계에 포함한다. 제외 공정의 배출량이 0이라는 의미는 아니다. 원단 생산 손실을 반영하지 않으므로 실제 의류 제조에 투입된 전체 섬유량의 배출량과도 구분한다.

섬유 생산 중 착색·첨가제가 포함된 계수는 해당 조건을 기록하고 임의로 차감하지 않는다. 0.2 개정에서 섬유 단계 착색과 후속 염색의 구분을 명확히 했다. [2차 계수 검토](CARBON_FACTOR_COMPATIBILITY_V2.md)를 참고한다.

## 3. 확보 가능한 입력과 가정

| 입력 | 확보 방법 | 처리 원칙 |
| --- | --- | --- |
| 소재·혼용률 | 라벨 OCR 및 사용자 수정 | 사용자 확인값으로 계산 |
| 의류 종류 | 사용자 선택 | 서버 카탈로그의 ID 사용 |
| 의류 무게 | 사용자 실측 또는 품목별 카탈로그 | 실측 우선, 출처 구분 |
| 소재 생산국·기술 | 일반 라벨만으로 확인 어려움 | 기본 계수의 가정 공개 |
| 겉감·안감·충전재 질량 | 일반 라벨만으로 확인 어려움 | 비율을 임의로 부여하지 않음 |
| 공정별 에너지·실제 공급망 | 제조사 자료 필요 | 초기 필수 입력에서 제외 |

`Made in`에 표시된 의류 제조국을 섬유 원료 생산국으로 사용하지 않는다. 재생·유기농 등의 조건도 확인 가능한 정보 없이 추론하지 않는다.

## 4. 초기 지원 조건

### 4.1 계산 가능한 경우

하나의 명확한 혼용률 그룹을 가진 의류를 우선 지원한다. 소재 비율이 전체 섬유 부분을 대표하며, 양의 비율을 가진 모든 소재에 사용 가능한 계수가 있어야 한다.

일반적인 총무게에는 부자재가 포함될 수 있다. 초기 모델에서 총무게를 섬유 무게의 대체값으로 사용할 경우 `total_garment_mass_as_fiber_proxy` 가정을 기록하고 화면에 알린다. 부자재가 많거나 가죽·코팅·충전재 등 제외 대상의 질량이 중요할 수 있는 품목은 단순 모델로 계산하지 않는다. 정량적인 부자재 차감률은 근거 없이 설정하지 않는다.

### 4.2 계산을 보류하는 경우

- 겉감·안감·충전재가 나뉘어 있고 각각의 질량을 모르는 경우
- 라벨이 겉감 등 일부 부위만 설명하고 전체 무게와 대응하지 않는 경우
- 미지원 소재 또는 기타 섬유 등 불명확한 소재가 양의 비율로 포함된 경우
- 비율이 불완전하거나 무게 정보가 없는 경우

예: 겉감 면 100%, 안감 폴리에스터 100%를 전체 50:50으로 합산하지 않는다. 알려진 소재만 계산한 값을 전체 의류의 결과로 표시하지 않는다. 보류 시 추출된 소재 정보는 제공하고 부족한 입력을 설명한다.

## 5. 소재 배출계수 선정

### 5.1 필수 메타데이터

각 후보에는 소재 표준명, 수치, 단위, 출처명·URL·표/페이지, 발행연도, 원자료 기준연도, 지역, 생산 방식, 버진/재생 여부, 시작·종료 공정, 영향평가 방법 및 시간 지평, 생물기원 탄소·토지이용변화 처리, 데이터 한계, 이용 조건을 기록한다. 확인되지 않은 항목은 미확인으로 남긴다.

### 5.2 선정 원칙

1. 수치가 제시된 원문과 조건을 직접 확인한다.
2. 원료·섬유·실·원단·의류 단위를 구분한다. 변환 근거가 없으면 상호 대체하지 않는다.
3. 함께 사용하는 계수는 계산 경계와 영향평가 방법이 호환되어야 한다. 주요 차이를 해결하지 못하면 선정 보류한다.
4. 생산 조건을 모르면 해당 조건 미상 상황에 적용 가능한 문헌 대체값을 검토한다. 개별 공장 사례를 세계 평균으로 표시하지 않는다.
5. 여러 연구의 값을 단순 평균해 기본값을 만들지 않는다. 통합할 경우 선택 기준, 가중치와 산출식을 기록한다.
6. 공개 열람 가능 여부와 앱 표시·데이터 재배포 가능 여부를 구분한다.
7. 소재 간 친환경 순위, 제품 간 비교 또는 절감량 주장은 초기 범위에 포함하지 않는다.

### 5.3 자료 구분과 사용 상태

자료의 출처 유형과 검토 상태를 별도로 관리한다. 문헌값을 특정 의류에 적용하는 행위 자체에는 추정이 포함될 수 있다.

| 필드 | 값 | 의미 |
| --- | --- | --- |
| evidence_type | literature | 원문에서 확인한 값 |
| evidence_type | derived | 문헌 또는 측정 자료에서 명시적 계산으로 산출한 값 |
| evidence_type | placeholder | 근거를 확보하지 못한 개발용 값 |
| review_status | candidate | 검토 중, 최종 계산용 미선정 |
| review_status | selected | 적용 조건과 한계를 검토한 뒤 팀이 선정한 값 |
| review_status | rejected | 범위 불일치 등으로 사용 제외 |

초기 사용자 계산에는 `selected` 계수만 사용한다. 기존 seed 값은 원출처 검증 전까지 `placeholder`로 분류한다. 앞서 조사한 Textile Exchange 면·폴리에스터 값은 후보이며 이 문서에서 기본값으로 확정하지 않는다.

## 6. 무게 기준

실측 무게가 있으면 범위보다 우선한다. 단위는 g로 입력받아 계산 시 kg으로 변환한다. 실측 무게는 사용자가 입력한 값으로, 서버가 독립적으로 측정·검증한 값은 아니다.

미측정 시에는 의류 종류 ID에 따라 서버가 카탈로그를 선택한다. 카탈로그에는 대표 무게, 하한·상한, 자료 출처, 실측/문헌/임시 여부, 표본 수(있을 때), 적용 사이즈·계절 조건, 범위 산출 방식과 버전을 기록한다. 현재 품목별 무게는 임시값으로 표시하며 실측 근거가 있는 것처럼 설명하지 않는다.

대표 무게는 카탈로그의 대표값을 사용한다. 범위 중간값을 사용할 경우 그 선택을 명시한다. 실제 표본 평균이나 중앙값이라는 근거가 없으면 해당 용어를 쓰지 않는다.

## 7. 계산과 입력 검증

```text
r_i = 사용자가 확인한 소재별 퍼센트
S = Σ r_i
p_i = r_i / S
f_i = 선정된 소재별 계수 [kg CO₂eq/kg fiber]
F = Σ (p_i × f_i)

C_rep = (대표 무게 g / 1000) × F
C_low = (하한 무게 g / 1000) × F
C_high = (상한 무게 g / 1000) × F
```

- 비율·무게는 유한한 수여야 한다. NaN과 무한대는 거부한다.
- 비율은 음수를 허용하지 않는다. 합계는 기존 호환 기준인 99.5~100.5%를 허용하고 S로 정규화한다.
- 표준명으로 확인된 동일 소재의 별칭은 병합하고 원래 입력도 보존한다.
- 0% 항목은 계산 대상에서 제외한다. 양의 비율을 가진 미지원 소재는 계산을 보류한다.
- 무게는 0보다 커야 하며 하한 ≤ 대표값 ≤ 상한이어야 한다.
- 실측 사용 시 대표·하한·상한 무게를 동일하게 설정한다.
- 계산 중간값은 반올림하지 않고, 최종 표시값만 소수 둘째 자리로 반올림한다. 반올림 방식은 구현 명세와 테스트에 고정한다.
- 의류에 적합한 입력 무게 상한은 별도 검증 후 구현 명세에 정의한다.

부위별 질량을 확보하는 후속 버전에서는 부위마다 위 계산을 수행해 합산할 수 있다. 초기 버전에서는 부위별 질량을 추론하여 이 확장식을 사용하지 않는다.

## 8. 결과 표현과 불확실성

결과 제목은 `소재 생산 단계 탄소배출 추정량`으로 한다. 대표값, 단위, 사용 무게와 출처, 소재별 계수와 출처, 포함·제외 단계 및 주요 가정을 함께 제공한다.

표시 문구 예시:

> 라벨의 소재 비율과 선택한 무게에 공개 자료의 계수를 적용한 추정치입니다. 원단 가공·의류 제조·사용·폐기 단계는 포함하지 않습니다.

총무게 대체 가정이 적용된 경우:

> 의류 총무게를 섬유 무게로 가정했습니다. 부자재 무게를 별도로 반영하지 못합니다.

무게 범위로 산출한 최소·최대는 `무게 가정에 따른 추정 범위`로 표시한다. 신뢰구간 또는 실제 배출량의 보장 범위로 표현하지 않는다. 실측 무게로 최소=최대가 되어도 계수와 생산 조건의 불확실성은 남는다. 임의의 ±오차율이나 근거 없는 정확도 점수를 부여하지 않는다.

## 9. 백엔드 저장 및 호환 요구사항

계산마다 다음 정보를 보존하여 이력 조회에서도 당시 계산을 설명할 수 있게 한다.

- 원본 입력과 표준화·정규화된 소재 비율
- 사용 무게, 무게 출처 및 카탈로그 버전
- 실제 적용한 계수 값·단위·출처·조건·계수 버전의 스냅샷
- 계산 범위·공식 버전·적용 가정·대표/하한/상한 결과
- 의류 종류 ID와 생성 시각

계수 변경 후 과거 결과를 자동으로 덮어쓰지 않는다. 재계산은 새로운 결과로 구분한다. 서버 시작 시 선정 계수를 seed가 덮어쓰거나 출처 컬럼이 제거되지 않도록 마이그레이션을 설계한다.

기존 `/analyze`의 혼합계수와 무게 기반 의류 추정 결과를 단위 및 이력에서 구분한다. 기존 프런트 필수 응답 필드는 호환을 검토하고, `average_carbon_footprint`는 통계적 평균으로 표시하지 않는다. API 변경 명세와 기존 데이터 보존 방법은 별도 구현 작업에서 확정한다.

## 10. 검증과 완료 조건

- 선정 계수마다 원문 수치와 적용 조건을 추적할 수 있다.
- 손계산 사례와 코드 결과가 일치하며 반올림 경계를 검증한다.
- 비율 경계·별칭 병합·미지원 소재·무게 오류·복합 라벨 보류를 검증한다.
- 실측 무게 우선 및 서버 카탈로그 선택이 일관되게 동작한다.
- 계수 변경 후에도 과거 이력의 값과 근거가 유지된다.
- 계산·저장·이력 조회와 프런트 표시가 같은 의미를 전달한다.

이 검증은 산술 정확성과 구현 일관성의 검증이다. 실제 제품 탄소발자국에 대한 정확도 검증에는 동일한 제품과 계산 경계의 독립적인 기준 자료가 추가로 필요하다.

1. 이 초안을 바탕으로 계산 경계와 초기 지원 조건을 팀에서 검토한다.
2. 면·폴리에스터부터 계수 검토표를 작성하고 호환 가능한 계수를 선정한다.
3. 자료 미확보 소재는 미지원으로 관리하고 조사 범위를 순차 확대한다.
4. 무게 카탈로그의 임시 상태를 명시하고 직접 측정 계획을 수립한다.
5. 계산 함수·저장 스키마·API 계약·테스트를 개편한다.
